# Contexto: frontend

Ultima actualizacion: 2026-11-07

## Que hace esta area

Pantallas de la app: mapa del predio (Leaflet + OpenStreetMap), ficha de suelo, deslizadores de prioridades, graficos de clima (Recharts) y comparador de las tres rotaciones. Todo en React + TypeScript + Tailwind, en español.

## Como esta hoy

- Todavia no existe el proyecto React. Solo estan las carpetas en `frontend/src/`.
- En `frontend/prototipos/` hay HTML de prueba de antes (no es la app final).
